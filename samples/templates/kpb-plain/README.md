# Шаблон «КПБ · однотонное, светлая спальня»

Сделан из фото однотонного белья → свет и складки сняты без потерь (без размытия).
Проверка: рендер исходным цветом `referenceColor` (#9bb1bc) отличается от фото в среднем на 1–3 из 255.

Формат = SPEC 5.7 + новые необязательные поля (см. kit/INTEGRATION.md, раздел 8):
| Поле / файл | Что это |
|---|---|
| `softMasks: true` | маски с мягким краем (0..255 = доля ткани). Края без «лесенки», стебли растений поверх ткани сохраняются |
| `light_<zone>.png` | цвет освещения (тёплый/холодный), RGB, value/255*2, 1.0 = 128 |
| `shadeKnee: 1.35` | блики сжимаются только выше 1.35 (на этом фото почти не сжимаются) |
| `highlightRolloff: true` | светлые цвета (белый, кремовый) не выгорают в чистый белый |
| `weaveCapable: true` + `weave_<zone>.png` | шаблон подходит и для страйп-сатина/жаккарда (режим weave) |
| `referenceColor` | цвет ткани на исходном фото — для проверки |

Зоны: fold (отворот), duvet (пододеяльник), pillowL, pillowR (наволочки 70×70). Сетка uv шагом 4 px,
рисунок слегка смещается по складкам.
