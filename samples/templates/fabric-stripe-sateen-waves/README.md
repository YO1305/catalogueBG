# Шаблон мокапа ТКАНИ: Ткань · страйп-сатин, волны
Изделие: fabric («Ткань»), вид: drape. Кадр целиком — ткань, 1 зона `fabric`.
Сделан из фото белой ткани ~3000 px. Фактура плетения сохранена попиксельно.
Поля: shadeScale 1.75 (shade = png/255*1.75), softMasks, light, shadeKnee 1.4, highlightRolloff.
Рекомендованный раппорт для превью: 10–20 см (кадр ≈ 30 см ткани по ширине).
ВНИМАНИЕ: на фото настоящий страйп-сатин — полосы «зашиты» в свет. Использовать для ТКАНЫХ (страйп-сатин): режим «Тканый рисунок → Без узора» + цвет. Для набивных рисунков не подходит.
