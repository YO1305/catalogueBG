# Шаблон «КПБ · спальня с тумбой»

Формат шаблона для системы каталога (раздел 5 SPEC.md). Получен из фото, без PSD.

| Файл | Что это |
|---|---|
| background.jpg | Исходное фото 2576×2576 |
| mask_<zone>.png | Маска зоны (белое = ткань) |
| shade_<zone>.png | Свет и складки белой ткани. Значение = png/255*1.5 (1.0 = нормальный свет) |
| template.json | Зоны, pxPerCm, uvGrid: координаты ткани в см в узлах сетки шагом 16 px |

Зоны: duvet (пододеяльник), fold (оборот), side (боковой свес), pillowL, pillowR (наволочки 70×70).

## Рендер
1. Для каждой зоны интерполировать uvGrid до пикселей (билинейно) → (u, v) в см.
2. Применить масштаб/поворот/сдвиг: пиксель рисунка = (u, v) × (ширина_рисунка_px / (раппорт_см × scale)), по модулю размера рисунка.
3. Цвет = рисунок × shade × tint_bgr × лёгкое зерно ткани.
4. Смешать с background по маске (край размыт на 1.2 px).

Эталонная реализация: ../render.py (Python/OpenCV). В веб-версии то же самое на WebGL.
