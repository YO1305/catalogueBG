# Шаблон «КПБ · страйп-сатин, спальня с изголовьем»

Формат тот же, что у шаблона КПБ (раздел 5 SPEC.md), плюс слои для сатина. `finish: "sateen"` в template.json.

| Файл | Что это |
|---|---|
| background.jpg | Исходное фото 1374×1145 |
| mask_<zone>.png | Маска зоны (белое = ткань) |
| shade_<zone>.png | Свет и складки без полоски. Значение = png/255*1.5 |
| weave_<zone>.png | Сила контраста «блестящая/матовая» полоса в каждой точке (зависит от угла света). Значение = png/255*0.5 |
| gloss_<zone>.png | Сатиновые блики на гребнях складок, 0..1, накладываются режимом screen |
| template.json | Зоны, pxPerCm, uvGrid (u, v в см, шаг 8 px). Ось v идёт ПОПЕРЁК полосок и повторяет изгибы складок, снятые с фото |

Зоны: duvet (пододеяльник), pillowL, pillowR. Период полоски на фото = 2.5 см (калибровка по наволочке 70 см).

## Два режима рендера (render.py)
1. **Генератор страйпа** — без файла рисунка:
   `render(t, out, stripes=[(1.25,'#f6f4f1',True),(1.25,'#f6f4f1',False)])`
   список полос: (ширина см, цвет, блестящая/матовая). Цвет можно разный — тогда это цветная полоска.
2. **Рисунок дизайнера**: `render(t, out, design='file.png', rapport_cm=40, scale=1, rot=0)`

## Формула
цвет = база(u,v) × shade × (1 + weave × контраст × ±1 для блестящей/матовой полосы) × tint
затем screen с gloss × сила_блеска (0.35 по умолчанию для сатина).
